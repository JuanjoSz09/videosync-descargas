# Video Sync · Descargas

Aquí está el instalador de **Video Sync** para Windows 10 y 11 (64 bits).

👉 **[Descargar el instalador](https://github.com/JuanjoSz09/videosync-descargas/releases/latest/download/VideoSync-Instalador.exe)**

Para usar la app necesitas una suscripción activa: al abrirla te pide tu clave.
La app se actualiza sola: no hace falta volver a descargar el instalador.

Si Windows dice «Windows protegió su PC», pulsa **Más información** y después **Ejecutar de todas formas**.
